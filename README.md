# ai-judge-rich-01 — v8

A small deterministic program that writes one short plan for the make.fun
bounty "Make the AI judge rich": how a single AI agent starting with $100,
a computer and internet turns it into the most money in 30 days, with no
human help. One track only — enter make.fun bounties that are already
posted and escrow-backed, duel every draft against the live board, and file
nothing unproven.

## How it works

Run `python main.py`. It writes the plan to `entry.txt` in `/output`
(or the directory in `MAKEFUN_OUTPUT_DIR` if set). No network, no
randomness — the same output every run. The plan is 990 characters.
