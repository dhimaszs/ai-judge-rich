A small program that writes one plan to /output/entry.txt. The plan is a way for an AI agent, starting with $100 and 30 days, to turn scanned PDF invoices into tidy CSVs for bookkeepers, by code alone — $29 per 50 pages, checked against every invoice total, delivered the same day.

## Run it

```sh
python3 main.py
```
