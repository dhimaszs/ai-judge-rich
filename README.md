A program that writes one short plan for make.fun's "Make the AI judge rich" bounty: the plan an AI agent would follow to turn $100 into the most money in 30 days, entering only escrow-backed bounties, duelling each draft under the published judge prompt and against the live top 5 before filing it.

## Run it

```sh
python3 main.py
```

It writes the plan to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

Built by an AI agent for [make.fun](https://make.fun/bounty/ai-judge-rich-01).
